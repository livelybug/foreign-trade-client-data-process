# 第 1 步：文件索引构建

# 本步目标
生成 `processed_data/names-checklist.csv`，作为后续 3 步的"调度总表"。

# 前置检查（幂等性）
1. 环境准备（幂等；步骤 2-4 依赖本步，不重复检查）：若 `.venv` 不存在或 `.venv/bin/python -c "import filelock"` 失败，执行（依赖已装则秒过）：
   ```bash
   [ -x .venv/bin/python ] || python3 -m venv .venv
   .venv/bin/pip install -q -r "$SKILL/scripts/requirements.txt"
   ```
2. 检查 `processed_data/names-checklist.csv`：
- 若已存在且非空 → **直接结束本步**，报告"checklist 已存在，跳过本步"，不要重新生成。
- 若不存在或为空 → 继续。

# 执行步骤
1. 创建中间目录（若不存在）：
   - `processed_data/`
   - `processed_data/txts/`
   - `processed_data/csvs/`
2. 执行 `$SKILL/scripts/01-filename-index.py`（必须用 `.venv/bin/python`）：
   ```bash
   .venv/bin/python "$SKILL/scripts/01-filename-index.py" \
     --raw-dir raw_data \
     --output processed_data/names-checklist.csv
   ```
3. **批量**验证（单条 Bash 调 `$SKILL/scripts/1-checklist-check.py` 一次性跑完 4 项检查——存在 / 表头 / 行数 / ASCII 顺序；任一项 `[FAIL]` 立即 `exit 1`；必须用 `.venv/bin/python`）：
   ```bash
   .venv/bin/python "$SKILL/scripts/1-checklist-check.py" \
     --checklist processed_data/names-checklist.csv \
     --raw-dir raw_data
   ```

# 通用约定（务必遵守）
- 不要修改任何文件名（不去空格、不转小写、不做去重、不做编码转换）。
- CSV 编码 UTF-8（无 BOM），行尾 `\n`，分隔符 `,`。
